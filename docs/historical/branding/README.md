# FamilyLock — Acervo de Recursos Gráficos e Identidad Institucional

Este directorio preserva los recursos gráficos originales e históricos del Centro de Atención Múltiple N.º 48 (CAM 48) de Nanchital, Veracruz.

## Catálogo de Identidad Visual

1. **Logotipo Vectorial Oficial (`public/logo-claro.svg` y `public/logo-oscuro.svg`)**:
   - Master vectorial en formato SVG, resolución infinita para imprenta, pantallas 4K y papelería oficial.
   - Incluye accesibilidad semántica, definición de trazos, tipografía curva y elementos inclusivos.

2. **Versiones Horizontales (`public/logo-horizontal-claro.svg` y `public/logo-horizontal-oscuro.svg`)**:
   - Diseñadas para barras de navegación, encabezados y pantallas de escaneo asistencial.

3. **Master Ráster Histórico (`Logo_del_CAM_original.png`)**:
   - Archivo ráster original sin comprimir (2048x2080 px, 32-bit RGBA) incorporado en el commit inicial (`00d10b2`).
   - Se preserva en este directorio como acervo histórico de diseño, liberando el directorio `public/` para optimizar los tiempos de despliegue y servicio web.

4. **Iconos PWA e Isotipos**:
   - `public/icono-512.png`: Icono de alta resolución para PWA y web manifests.
   - `public/favicon.svg` e `isotipo-cam.svg`: Escudo circular vectorial para favicons y credenciales escolares.
